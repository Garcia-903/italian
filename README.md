# Italian

Sistema de gestión para una agencia de viajes, orientado a la administración de usuarios y reservas de viajes nacionales e internacionales.

## Descripción del proyecto

Este proyecto está diseñado como una base para una aplicación web de viajes, con módulos dedicados a:

- Registro de usuarios
- Gestión de reservas nacionales
- Gestión de reservas internacionales
- Estructura inicial para futuras funcionalidades de administración y flujo de ventas

## Estructura del proyecto

```text
italian/
├── README.md
├── GESTION_USERS/
│   └── REGISTRO.html
├── GESTION_VIAJES_NAC/
│   └── RESERVACIONES.html
├── GESTION_VIAJES_INT/
│   └── RESERVACIONES.html
└── .git/
```

## Módulos incluidos

### 1. Gestión de usuarios
Carpeta: `GESTION_USERS`

- Archivo: `REGISTRO.html`
- Funcionalidad objetivo: registrar nuevos usuarios o clientes de la agencia.

### 2. Gestión de viajes nacionales
Carpeta: `GESTION_VIAJES_NAC`

- Archivo: `RESERVACIONES.html`
- Funcionalidad objetivo: manejar reservas de viajes dentro del país.

### 3. Gestión de viajes internacionales
Carpeta: `GESTION_VIAJES_INT`

- Archivo: `RESERVACIONES.html`
- Funcionalidad objetivo: manejar reservas de viajes hacia otros países.

## Tecnologías

El proyecto actualmente se basa en una estructura web estática con archivos HTML, pensada para ser ampliada con:

- HTML5
- CSS3
- JavaScript
- Frameworks o backend según el crecimiento del sistema

## Cómo ejecutar el proyecto

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto en tu editor.
3. Ejecuta cualquiera de los archivos `.html` en el navegador.
4. Si prefieres, puedes usar la extensión Live Server de VS Code para visualizar los archivos más cómodamente.
